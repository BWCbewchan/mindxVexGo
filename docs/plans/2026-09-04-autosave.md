# Auto save option

Reuse the existing GO project serializer and browser restore path. Keep automatic
browser saving enabled by default, expose an on/off switch inside the File menu,
and persist the choice. Save changed projects every two seconds and when the page
is hidden. Keep manual file downloads independent. Report actual storage failures
instead of showing Saved. The saved project remains local to this browser.

Implementation: guard the vendor save method before startup; wrap saves in the
bridge to detect changes and report status; add the File menu switch and responsive
styling; verify save, reload, disabled persistence, and storage failure in browser.
