# Quiz Implementation Plan

Goal: Publish all 72 supplied homework originals and add source-backed practice quizzes at /quiz.
Architecture: Static catalog plus per-document JSON loaded on demand. Source files remain unchanged, with SHA-256 provenance. PDF pages render as web images; DOCX paragraphs/tables and embedded images render in reading order. Quiz answers, best scores and drafts remain local. No account or cross-device reporting is claimed.
Tech stack: Next.js App Router, React, TypeScript, Python OOXML and PyMuPDF.

1. scripts/import-homework.py inventories and copies every PDF/DOCX to stable ASCII paths; outputs manifest, reading content and extraction report. Compare SHA-256 hashes and counts.
2. Read extracted text by curriculum. Create authored MCQs with unique distractors, correct answer, explanation and source evidence; do not infer unreadable image contents. Preserve source language and label as adapted practice.
3. /quiz gallery provides curriculum filters, search, lesson cards and saved progress. Lesson reader shows complete imported source content and original download.
4. Quiz runner provides one-question flow, answer navigation, submission with result/explanations, retry, local drafts and best scores; validate restored storage and communicate storage failures. Use custom dialogs only.
5. Link Quiz from home and Classroom. Verify complete import, answer indices/evidence, document/image HTTP loading, quiz scoring/retry/reload, keyboard flow and mobile overflow. Build before completion. Do not push.
