# VEX GO Web Implementation Plan

**Goal:** Deliver a locally running Next.js web version of the provided VEXcode GO APK, with responsive access and clear hardware compatibility.

**Architecture:** Preserve the extracted application as an isolated same-origin editor. Next.js provides the responsive entry point, help and editor container. Adapt native-only boot and file handling only where source inspection and browser tests show it is necessary. Preserve vendor attribution and the original extracted files.

**Tech Stack:** Next.js App Router, React, TypeScript, original React/Blockly runtime, browser file APIs.

1. Inspect the bundled platform detection and boot path; identify native dependencies.
2. Create a reproducible asset preparation script with guarded patches; keep original APK assets intact.
3. Implement Next.js shell, editor and mobile layout, with accurate Bluetooth availability information.
4. Exercise the editor in a browser: boot, block editing, project save/open, desktop/mobile layouts.
5. Build production output, run it, document local/LAN usage and HTTPS hardware requirements, and open the result.

User approved the recommended reuse approach and autonomous implementation. No unrelated repository initialization or changes are needed.
